# Kizo Host 2.0.0 (5)

- Rebuilt as a native React Native Android application instead of a WebView wrapper.
- Added native email registration and login, profile completion, host verification status, profile gallery crop/rotate controls, and account settings.
- Added realtime discovery, direct and random chats, delivery/read receipts, unread counters, blocking, reporting, ratings, tips, wallet, and withdrawal status.
- Added native Agora audio/video calling with incoming-call UI, second-based server billing, busy-state protection, in-call tips, and app-to-web interoperability.
- Added Firebase/Notifee message and incoming-call notifications with accept/decline actions and branded notification icons.
- Added Cloudinary unsigned profile/chat media uploads, Android camera/media permissions, device registration, presence, and device-ban enforcement.
- Added padded adaptive launcher artwork, fixed safe-area navigation, and signed ARM release artifacts.
